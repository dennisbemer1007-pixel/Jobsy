Lesbrief — Lobsy ontdekkingsreis

Deze lesbrief wordt on-demand getoond (niet vooraf gegenereerd als PDF).

Voorbereiding

  • Print de codelijst (lege naamkolom) en vul namen zelf in op papier.
  • Bevestig dat ouders zijn geïnformeerd.
  • Open het testvenster voor de klas.

In de les (~25 min)

  1. Leerlingen gaan naar lobsy.nl/leerling.
  2. Kies school + klas + code van de lijst.
  3. Beantwoord 60 vragen; progressie wordt bewaard.
  4. Bij pauze: leerling klikt Pauze (sessie eindigt op gedeelde Chromebooks).

Privacy

Lobsy bewaart geen namen. Geen AI, geen vacatures, geen reclame.
