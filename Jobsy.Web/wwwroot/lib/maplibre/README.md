# MapLibre GL JS (vendored)

Local copy of [MapLibre GL JS 5.24.0](https://maplibre.org/) so the homepage does not block on a CDN and CSP stays `'self'` for scripts.

Used with OpenFreeMap vector styles:

- Liberty: `https://tiles.openfreemap.org/styles/liberty`
- Bright (3D camera): `https://tiles.openfreemap.org/styles/bright`
