## Goal
The schoolbeheerder can run the whole school side: create classes, get codes, print the code list (empty name column), invite teachers bound to their own classes (2FA verplicht), confirm that parents were informed, open/close the test window, and see results. Results are per code only when the admin setting allows it (D4), otherwise per-class totals.

## 02.2 Dashboard `/school` + Te doen `/school/te-doen` (sc-s1)
- KPI row (`EntKpiCard`): **Klassen** · **Leerlingcodes** · **Test afgerond** (n + % of codes) · **Leraren** (with "x zonder 2FA" when any are still pending enrollment).
- Card **"Tests per klas"**: table Klas · Leraar · Codes · Gestart · Afgerond (progress bar + %) · Testvenster (pill Open/Dicht/Nog niet open + date) · row link to the class.
- Card **"Te doen"** (max 5, "Alles bekijken" → `/school/te-doen`), generated by `SchoolTodoBuilder`:
  - class without parental confirmation
  - class without a leraar
  - teacher invite pending > 3 days
  - window closes within 3 days with < 80 % completed
  - pupil-login pause triggered (04.3)
  - retention cutoff within 30 days ("Op 31 juli worden de leerlinggegevens van 2026–2027 verwijderd. Download wat je nodig hebt.")
- Card **"Interesses hele school"**: RIASEC top-3 distribution over all completed pupils, only when ≥ 5 completed; else the empty state "Zichtbaar vanaf 5 afgeronde tests."
- Page intro line "Lobsy bewaart geen namen. Codes koppel je zelf aan leerlingen." (as in the mockup).

## 02.3 Klassen & codes `/school/klassen`, `/school/klassen/{classId}` (sc-s2)
- List: table Klas · Niveau · Leerjaar · Leraar(en) · Codes · Afgerond · Ouders (pill "Bevestigd"/"Nog bevestigen") · Testvenster. Filter by school year (default current). Primary **"Nieuwe klas"**.
- Drawer **Nieuwe klas**: Klasnaam, Niveau, Leerjaar, **Aantal leerlingen** (1–40), Leraar(en) (multi-select from the school's teachers, optional), Schooljaar (default current, from `SchoolYear.Current(today, cutoff)`). Note: "Lobsy maakt voor elke leerling een code. Namen vul je zelf in op de geprinte lijst." Submit creates the class + N codes in one transaction.
- Class detail:
  - header with the class actions: **Codelijst printen (PDF)**, **Download CSV**, **Codes erbij** (+n, max total 40), **Testvenster**
  - code table # · Code (monospace, shown in full; SchoolAdmin/teacher only) · Status pill (Nog niet gestart / Bezig x/60 / Afgerond) · Laatst actief (relative) · row menu **Nieuwe code** (confirm: "De oude code werkt dan niet meer. De antwoorden blijven bewaard.") and **Code verwijderen** (outline-danger; confirm with the text "Alle antwoorden en uitkomsten van deze code worden direct verwijderd. Gebruik dit bij bezwaar van ouders of leerling. Dit kan niet ongedaan worden.")
  - edit class (name, level, year, teachers), **Klas verwijderen** (danger, deletes everything incl. codes; confirm types the class name)
- Server:
  - `api/school/classes` (CRUD)
  - `…/{id}/codes` (list / add / replace / delete)
  - `…/{id}/codelist.pdf` and `…/{id}/codelist.csv`

  All scoped via `SchoolScopeService`; a foreign school's class id → 404.

## 02.4 Code list PDF + CSV (sc-s2 code list panel)
- `ISchoolCodeListPdfService` (QuestPDF), A4 portrait:
  - header: school, class, school year, "Codelijst — bewaar deze lijst op school"
  - table columns **Nr · Code · Naam (vul zelf in)** (empty, lined, wide)
  - footer: "Lobsy bewaart geen namen. Deze lijst blijft op school. Leerlingen loggen in op lobsy.nl/leerling met school, klas en code."
  - optional second page "Kaartjes om uit te knippen": per code a small card with school, class, code and URL, and **no name line**
  - Generated on demand, **never stored**; response `Cache-Control: no-store`.
- CSV (UTF-8 BOM, `;` separator for Dutch Excel): fixed header `Nr;Code;Naam (vul zelf in)`, the name column always empty. Test asserts the exact header and that column 3 is empty on every row.
- Download logged (`PersonalDataAccessLog`, resource `school.codelist`, action `pdf`/`csv`, `SubjectCompanyId` none, class id in the details).

## 02.5 Ouders + testvenster (sc-s2 confirmation box, §P, D6/D7)
- Class detail card **"Ouders informeren"**:
  - text: "Lobsy is een hulpmiddel van school. De school is verantwoordelijk voor de gegevens; Lobsy verwerkt ze in opdracht. Informeer ouders vóór de test en geef ze de kans bezwaar te maken."
  - link **Ouderbrief (voorbeeld)** → `/school/privacy#ouderbrief`
  - checkbox + button **"Ik bevestig: ouders van klas {X} zijn geïnformeerd"** → sets `ParentalInfoConfirmedAtUtc/ByUserId/TextVersion`. Shows "Bevestigd op {datum} door {naam}" after. Can be withdrawn only while the window has never opened.
- **Testvenster** (dialog, shared component `TestWindowDialog` reused by 03):
  - state pills; **Openen** (optional close date ≥ today, ≤ cutoff), **Sluiten**, **Opnieuw openen**
  - server 409 `processor_agreement_missing` / `parental_info_missing` with a friendly message and a link to fix it
  - auto-close: a small hourly job or check-on-read (`TestWindowAutoCloser`) closes windows whose date passed (Europe/Amsterdam)
- API `POST api/school/classes/{id}/parental-confirmation`, `POST …/test-window` `{action, closesOn?}`.

## 02.6 Leraren `/school/leraren` (sc-s3)
- Table: Naam · E-mail · **Eigen klassen** (chips) · 2FA (pill "Aan" / "Nog instellen") · Status (Uitgenodigd/Actief) · Laatst ingelogd · row menu (Klassen wijzigen, Opnieuw uitnodigen, Verwijderen). Filter **Klas**. Primary **"Leraar uitnodigen"**.
- Drawer **Leraar uitnodigen** (exactly sc-s3; **no role choice**):
  - Naam, School-e-mail (domain hint "moet eindigen op @voorbeeldcollege.nl")
  - **Klassen** (checkbox list of the school's current-year classes)
  - info box "Een leraar ziet alleen de klassen die je hier aanvinkt. Uitslagen per code, verhaal en PDF: alleen van die klassen."
  - locked row "Tweestapsverificatie · Verplicht" with the line "Na de eerste keer inloggen stelt de leraar een authenticator-app in. Inloggen met Microsoft of Google van school telt ook."
  - Primary "Uitnodiging versturen".
- A schoolbeheerder can tick themselves as leraar of a class (D2): the same `TeacherClassAssignment`.
- Removing a teacher: deactivates the account, removes assignments. Classes without a teacher show in Te doen.
- API `api/school/teachers` (list/invite/assign/revoke/remove).

## 02.7 Resultaten `/school/resultaten?klas={id}` (sc-s4, D4)
- Class selector (tabs or select). Per class:
  - **Totals card** (always, only when ≥ 5 completed, else the empty state): completion, RIASEC top-3 distribution, top drijfveren, droombanen with "Overig" < 2
  - **Per code table** only when `SchoolPerCodeResultsEnabled`: Code · Status · Interessecode (e.g. "SA · Helpen & Maken") · Top-drijfveer · Droombaan. Panel pill "Per code: aan" and note "Lobsy-beheer kan 'resultaten per code' uitzetten. Dan zie je alleen totalen per klas (vanaf 5 leerlingen)." Below it: "Verhaal, likes en PDF per code ziet alleen de leraar van de klas."
  - Setting **off**: no per-code table, pill "Per code: uit", note "Je ziet alleen totalen per klas. Resultaten per code ziet de leraar."
- **Server-enforced:** `GET api/school/classes/{id}/results` returns `perCode: null` when the setting is off (DTO field absent/null, not just hidden). Test both. No endpoint under `api/school` ever returns story, likes, dislikes, fit route or raw answers.
- Totals come from a shared `ClassResultsAggregator` (Core, pure): input = results of a class; output = counts with k-anonymity applied. 03 and 07 reuse it.

## 02.8 Schoolgegevens, Privacy & ouders, Lesbrief & materiaal
- `/school/gegevens`: read-only school data + allowed domains + "Wijzigen? Neem contact op met Lobsy."
- `/school/privacy`:
  - verwerkersovereenkomst status (date + version)
  - who is controller/processor
  - retention line "Leerlinggegevens worden op {31 juli} na het schooljaar verwijderd. Anonieme totalen (vanaf 5 leerlingen) blijven voor rapportage."
  - per-class confirmation list
  - **Ouderbrief** section (static nl text, copy button + PDF download) explaining: what the test is, codes only, no names, no AI, no vacancies/advertising, who sees what, retention, how to object (via school)
- `/school/materiaal`: lesbrief (static PDF from `wwwroot/docs/scholen/lesbrief-lobsy.pdf`, generated once via QuestPDF at build time **or** rendered on demand from static text; pick one and say so) + "Zo loggen leerlingen in" steps.
