# Strakke kandidaat-onboarding (plain)

Dit is de goedgekeurde strakke kandidaat-onboarding (akkoord Dennis 27-10-2026) en wordt de standaard in de app. De geillustreerde stijl komt achter een boolean feature flag.

## Gids-kreeft

Op desktop staat de gids-kreeft rechts. Op mobiel is dat een ingeklapte regel van 54px met **Voorlezen** (`speechSynthesis`, `nl-NL`). Per scherm een andere pose.

## Tests

Eén vraag per scherm, schaal van 1 tot 5 («Past niet» tot «Past heel goed»), praktijkvoorbeeld onder de stelling, knoppen Terug/Volgende, geen pauzescherm.
