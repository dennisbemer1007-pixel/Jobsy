# Banenkaart (goedgekeurd 22 oktober 2026, 22:54)

Versie met filterlade (desktop) en paneel dat omhoog schuift (mobiel).

Eisen van Dennis:
- Alle knoppen moeten werken (filters, lade open en dicht, pins, lijst, opslaan).
- Laadtijd is erg belangrijk: de kaart moet snel zichtbaar en bruikbaar zijn, ook op mobiel.
- Bouwen op dezelfde manier als de onboarding: simpele knoppen met JS, opslaan per actie via dezelfde server, volledige navigatie, zichtbare foutmelding.
