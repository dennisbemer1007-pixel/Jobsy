Zo werkt het

  1. Maak een klas aan en kies het niveau.
  2. Print de codelijst en houd zelf bij welke code bij wie hoort.
  3. Bevestig dat ouders zijn geïnformeerd.
  4. Plan het testvenster. Alleen dan kunnen leerlingen inloggen.

Codes vervangen

Code kwijt of verkeerd uitgedeeld? Vervang hem in de klas. De oude code werkt dan niet meer.

Einde schooljaar

Op 31 juli 2027 worden alle codes en antwoorden van dit schooljaar verwijderd. Groepscijfers blijven bewaard.
