# Lobsy

Hyper-local job matching for Westland and The Hague (and beyond). Candidates search by **travel time and transport mode**; employers reach nearby talent without traditional job-board noise. The public brand is **Lobsy**; the code, repo, and infrastructure keep the historical name **Jobsy** (see [`docs/adr/0001-keep-jobsy-code-name.md`](docs/adr/0001-keep-jobsy-code-name.md)).

## Stack

| Layer | Choice |
|-------|--------|
| Frontend | .NET 10 **Blazor Server** (`Jobsy.Web`) |
| API | ASP.NET Core Web API (`Jobsy.Api`) |
| Domain / data | `Jobsy.Core` ← `Jobsy.Infrastructure` (EF Core, PostgreSQL + PostGIS) |
| Map | **MapLibre** GL (local CSP build) + OpenFreeMap tiles |
| Hosting | **Render** (Production `lobsy.nl`, Acceptatie `acceptatie.lobsy.nl`) |

## Run locally

**Prerequisites:** [.NET 10 SDK](https://dotnet.microsoft.com/), Docker (Postgres/PostGIS), `dotnet tool restore`.

**Option A — CI-style stack** (API `:5200` + Web `:5201`, seeded Development):

```bash
# Postgres with PostGIS on localhost:5432 (e.g. postgis/postgis:16-3.4), then:
dotnet restore Jobsy.sln && dotnet build Jobsy.sln -c Release
chmod +x .github/scripts/start-ci-stack.sh
.github/scripts/start-ci-stack.sh
```

**Option B — two terminals:**

```bash
dotnet tool restore
dotnet tool run dotnet-ef database update -p Jobsy.Infrastructure -s Jobsy.Api
dotnet run --project Jobsy.Api --launch-profile http   # http://localhost:5200
dotnet run --project Jobsy.Web --launch-profile http   # http://localhost:5201
```

Default connection string: `Host=localhost;Port=5432;Database=JobsyDb;Username=postgres;Password=postgres` (see `Jobsy.Api/appsettings.json`).

### Transactional mail

`Mail__Provider` is `Resend` or `Lettermint`. Lettermint (https://lettermint.co, Dutch company, mail stays in the EU) sends only when `Lettermint__ApiKey` is set. Without that key, mail is not sent and Lobsy logs an error once. Resend is used only when `Mail__Provider` is `Resend`. Acceptatie sets `Mail__AllowedRecipientPattern` to `^test-[^@]+@lobsy\.nl$` and can add the admin address as `Mail__AllowedRecipientAddresses__0`. Production leaves the pattern empty, so every recipient is mailed. Full list: [`docs/deploy-render.md`](docs/deploy-render.md) and [`docs/email-deliverability.md`](docs/email-deliverability.md). No secret values belong in git.

### Demo users

Seeded only in Development / when `Seed:Enabled` is on. Accounts live in [`Jobsy.Infrastructure/Data/DemoUsersSeeder.cs`](Jobsy.Infrastructure/Data/DemoUsersSeeder.cs) (`@jobsy.local` emails). The shared public demo password is the constant `DemoUsersSeeder.DemoPassword` (`Jobsy123!`). Not available on Production Render (`AllowDevelopmentAuth=false`).

## Bronnen

Job titles come from ESCO v1.2.1 (European Commission). Interest profiles per job come from the O*NET 31.0 Database (U.S. Department of Labor / Employment and Training Administration), used under CC BY 4.0. Lobsy has modified some of that information. USDOL/ETA has not approved, endorsed, or tested those modifications. The ESCO–O*NET crosswalk is European Commission & U.S. Department of Labor (2022). Dutch job titles in the search index also use CBS, Beroepenclassificatie BRC 2014 editie 2025 (CC BY 4.0). Skill names on the current-job tip come from the same ESCO list. Demand up to 2030 comes from ROA, AIS tot 2030, editie 2026 (CC BY 4.0); the current tension indicator and the 2025–2030 direction come from UWV via ROA. Task exposure comes from Gmyrek et al., ILO Working Paper 140 (2025), CC BY 4.0, shortened and translated by Lobsy. That adaptation is not an official ILO text. The public page is `/bronnen`.

The catalogue is generated by `tools/occupations/` and committed as JSON. See `tools/occupations/README.md`.
